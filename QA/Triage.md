# CardThrow — баг-репорты и триаж (T2)

Шаблон: `.github/ISSUE_TEMPLATE/bug.md`. На GitHub: Issues → New issue → «Баг».
Ссылку на каждое новое Issue кидаем в тему #bugs в Telegram.

## Правила триажа

1. **P0 — блокирует запуск или прохождение** (проект не открывается, красная ошибка в Console, игра зависла, нельзя пройти уровень, R не работает). Владелец бросает всё и чинит; Артас пишет в #bugs с пометкой «P0».
2. **P1 — заметит жюри** (неверный исход, превью врёт, нет звука или реакции на действие, кривой UI, текст не влезает). Чиним до M4, 12.10 23:00.
3. **P2 — косметика.** Чиним только когда P0 и P1 пусты. **После M4 не трогаем**, кроме чисел в ScriptableObject.
4. **Кому назначать** — по владению из CLAUDE.md, раздел 7 (таблица ниже). Если непонятно — Даниле, он переназначит.
5. **Разработчик должен воспроизвести баг за минуту:** шаги начинаются с ▶ Play, указаны уровень и состояние игры, приложены видео и полный текст ошибки из Console.
6. **Закрывает Issue Артас**, после проверки на свежем Pull. Не воспроизвелось — комментарий с хешем коммита и закрыть. Повторилось — открыть заново.

Метки, которые нужно создать в репо (Issues → Labels → New label): `bug` (уже есть по умолчанию), `P0`, `P1`, `P2`. Шаблон ставит только `bug`; приоритет пишем в названии `[P1]` и ставим метку вручную.

## Пример идеального баг-репорта

> Пример вымышленный — показывает уровень детализации.

**Название:** `[P0] R во время слоу-мо оставляет игру замедленной`

**Приоритет:** P0
**Где:** уровень 1 · **Состояние:** слоу-мо после Success · **ID:** RST-05

**Шаги**
1. ▶ Play → «Играть» → Tab (пропустить обучение).
2. На уровне 1 выбрать карту 7 (D один раз), закрут 0, бросить в зону напарника.
3. Пока идёт слоу-мо после «BLACKJACK!», нажать R.

**Ожидалось:** забег начинается заново, игра идёт с нормальной скоростью.
**Получилось:** баннер уровня висит примерно 4 с вместо 1.2 с, карта летит в замедлении, таймер уровня тикает медленнее секундомера.
**Частота:** 10 из 10.
**Видео:** `rst05_slowmo.mp4` (12 с).
**Console:** ошибок нет.
**Версия:** коммит `a1b2c3d`, Unity 6000.6.5f1, Windows 11, Game — 16:9.

**Назначить:** Данила (рестарт и состояния). Возможная причина для разработчика: `RestartRun()` не возвращает `Time.timeScale = 1`, если слоу-мо прервали.

### Предложения команды

- **Уровень 2 слишком сложный** — стакан маленький, в него трудно попасть для рикошета. Сейчас коллайдер стакана r = 0.3 при радиусе карты 0.25. Предложение: увеличить стакан до r ≈ 0.45 (префаб Glass — Алексей, спрайт 0.6 ед. — Кирилл) или поставить его ближе к линии броска (Hand_02 — Егор).
- **Уровень 3 сложный, но как финал слабоват** — нет новой механики, ощущается как «ещё один уровень». Параметры расходятся с планом: время 20 с (план 15), превью 100% (план 45%) — сложность создаёт расстановка, а не видимые ручки. Финалу нужно «новое»: движущийся поднос из A4 (Алексей, 12.10 до 12:00), цепная реакция фишек, может, золотая фишка-бонус. Решение — Егор + Данила.
