# CardThrow

Игра для FunFlow Game Jam × ТПУ, вариант «Катапульта».

Ты — крупье-шулер. Пока игроки отвернулись, щелчком отправь через весь стол нужную карту напарнику (он в золотом контуре), чтобы у него стало ровно 21. Не задень бутылки и карточные домики и не попади к чужим игрокам — иначе тебя раскроют.

## Как запустить

1. Установите **Unity 6000.6.5f1** (строго эта версия) через Unity Hub.
2. Скачайте репозиторий: **Code → Download ZIP** и распакуйте, или `git clone https://github.com/KYBOEB/CardThrow.git`.
3. Unity Hub → **Add** → **Add project from disk** → выберите папку `CardThrow`. Первый импорт займёт несколько минут.
4. Откройте сцену `Assets/_Project/Scenes/Main.unity` (обычно открывается сама).
5. Нажмите **▶ Play** вверху редактора. Игра идёт в окне **Game**.
6. Для лучшего вида в окне Game включите **Play Maximized** (выпадающий список «Play Focused» на панели окна Game) или наведите курсор на окно Game и нажмите **Shift+Space**, чтобы развернуть его.

Если клавиши не реагируют, кликните один раз по окну Game: Unity передаёт ввод с клавиатуры только окну в фокусе.

## Управление

| Действие | Основное | Дублирование |
|---|---|---|
| Начать игру | Space / Enter | — |
| Выбрать карту из трёх | A / D | ← / → |
| Прицелиться и задать силу | Зажать ЛКМ и тянуть **назад** (как рогатка) | — |
| Бросок | Отпустить ЛКМ | — |
| Закрут (−3…+3) | Колёсико мыши (1 щелчок = 1 шаг) | Q (влево) / E (вправо) |
| Отменить прицел | ПКМ или Esc | — |
| Рестарт забега | R | Кнопка на экране |
| Пропустить обучение | Tab | — |
| Перейти к уровню 0–3 | Shift + 0…3 | — |

Положительный закрут (+) уводит карту дугой **влево**, отрицательный (−) — **вправо**.

## Правила коротко

- Сумма напарника плюс номинал брошенной карты должна быть ровно **21**, а карта должна остановиться в его зоне.
- Задел бутылку или карточный домик, перебор или недобор, вылет со стола, не успел до конца таймера → **подозрение +1**. Три подозрения — поражение.
- Карта в зоне соперника — мгновенное поражение: «Шулер!».
- Обучение и 3 уровня: с каждым уровнем меньше времени, короче подсказка траектории и больше препятствий.
