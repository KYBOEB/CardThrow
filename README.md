# CardThrow

Игра для FunFlow Game Jam × ТПУ, механика «Катапульта».

Ты — крупье-шулер. Пока игроки отвернулись, оттяни карту, как рогатку, и отправь её через весь стол напарнику в золотом контуре, чтобы у него стало ровно 21. Закручивай карту в обход ведёрок с шампанским, отражай от стаканов и не попадай к чужим игрокам — иначе охрана выведет тебя из казино.

## Как запустить

1. Установите **Unity 6000.6.5f1** (строго эта версия) через Unity Hub.
2. Скачайте репозиторий: **Code → Download ZIP** и распакуйте или выполните `git clone https://github.com/KYBOEB/CardThrow.git`.
3. Unity Hub → **Add** → **Add project from disk** → выберите папку `CardThrow`. Первый импорт займёт несколько минут.
4. Сцена `Assets/_Project/Scenes/Main.unity` откроется сама (если нет — откройте её двойным кликом).
5. Нажмите **▶ Play** вверху редактора. Игра идёт в окне **Game**.
6. Для лучшего вида разверните окно Game: включите **Play Maximized** (выпадающий список «Play Focused» на панели окна Game) или наведите курсор на окно Game и нажмите **Shift+Space**.

Если клавиши не реагируют, кликните один раз по окну Game: Unity передаёт ввод с клавиатуры только окну в фокусе.

## Управление

| Действие | Основное | Дублирование |
|---|---|---|
| Начать игру | Space / Enter | Кнопка на экране |
| Выбрать карту из трёх | A / D | ← / → |
| Прицелиться и задать силу | Зажать ЛКМ и тянуть **назад** (как рогатку) | — |
| Бросок | Отпустить ЛКМ | — |
| Закрут (−3…+3) | Колёсико мыши (1 щелчок = 1 шаг) | Q (влево) / E (вправо) |
| Отменить прицел | ПКМ или Esc | — |
| Начать забег заново | R | Кнопка на экране |
| Пропустить обучение | Tab | — |
| Перейти к обучению / уровню N (только в редакторе) | Shift + 0 / Shift + 1…5 | — |

Положительный закрут (+) уводит карту дугой **влево**, отрицательный (−) — **вправо**. Пунктир перед броском показывает настоящий путь карты, с отскоками от стаканов.

## Правила

- Сумма очков напарника плюс номинал брошенной карты должна быть ровно **21**, а карта должна остановиться в его зоне.
- У тебя **3 сердца**. Промах (задел ведёрко с шампанским или карточный домик, перебор или недобор, карта улетела со стола или не долетела, не успел до разворота соперников) отнимает сердце, каждый BLACKJACK возвращает одно. Три промаха подряд — поражение.
- Карта в зоне соперника — мгновенное поражение: «Шулер!».
- Очки за успешный бросок: база + оставшееся время + точность + рикошеты + закрут. Рекорд сохраняется.
- В обучении промахи не штрафуются.

## Уровни

Забег занимает около 5 минут.

| № | Раздача | Чему учит |
|---|---|---|
| О1 | Бросок | Выбрать карту и бросить прямо |
| О2 | Закрут | Обойти ведёрко закрутом |
| О3 | Рикошет | Отразить карту от стакана |
| 1 | Первая раздача | **Закрут**: ведёрко на пути, обход дугой |
| 2 | Рикошет | **Рикошет**: прямой путь закрыт, только через стакан |
| 3 | Стена | **Закрут + фишки**: стена из карточных домиков, фишки отталкиваются картой |
| 4 | Перекидка | **Тайминг**: соперники двигают ведёрко по столу туда-обратно, бросай, когда путь свободен |
| 5 | Большой куш | **Всё вместе**: мало времени, короткий прицел, соперники рядом с напарником |

С каждым уровнем меньше времени и короче подсказка траектории (100% → 45%).

## Архитектура

- **Одна модель полёта** (`FlightSimulator.StepWithCollisions`) считает и сам бросок, и пунктир превью, поэтому превью никогда не врёт: закрут, трение, отскоки от стаканов, удары о фишки.
- **`GameManager`** — машина состояний: Title → HandIntro → Aiming → Flying → Resolving → HandResult → GameOver / Victory.
- **`GameEvents`** — статические C#-события. Геймплей, UI, звук (`SoundEventsBridge`) и эффекты (`FeedbackManager`) не знают друг о друге, только подписываются на события.
- **Настройки в ScriptableObject** (`Assets/_Project/Data/`): `FlightSettings`, `GameSettings`, `UiTexts` (все тексты), `SoundLibrary` (SoundId → клипы). Баланс правится без кода.
- **Уровни — префабы** `Prefabs/Levels/Hand_0N` с компонентом `LevelConfig` (места соперников и напарника, карты, время, длина превью). `LevelManager` загружает их по списку в `Main.unity`. Проходимость каждой раздачи проверяется перебором бросков в редакторе (меню **CardThrow → Уровни: проверить проходимость**).
